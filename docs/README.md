# docs 目录说明

本目录存放项目的**长期有效文档**，会随代码一起进 Git。

## 目录约定

| 路径 | 用途 |
|---|---|
| `CHANGELOG.md` | **改动思路记录**：每次修改代码都要追加一条，写清「改了什么 + 为什么这么改」，不写流水账 |
| `日志/YYYY-MM-DD.md` | 每日工作日志，记录当天做了什么、踩了什么坑 |
| `README.md` | 本文件，目录约定 |

## 硬性规则

1. `.workbuddy/` 已加入 `.gitignore`，**不进 Git**。它是本机工作记忆，正式内容一律落到 `docs/`。
2. 每次改代码，**必须在 `CHANGELOG.md` 顶部追加一条**，格式见文件内模板。只改注释/格式也要记一笔。
3. 登录态 `output/douyin/storage_state.json` 含 Cookie 凭证，`output/` 已忽略，**永远不要提交**。
4. 一次性探针、调试输出（如 `_probe*`、`_check*`）用完即删，也已加入忽略规则。
