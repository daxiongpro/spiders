# 【重要更正】上面第 44-46 行的"妙记异步坑"结论是错的

`lark-cli vc +notes` **这个命令根本不存在**！本机 lark-cli（1.0.94 / 1.0.95）

## 正确的妙记转写命令链（已实测跑通）
```
lark-cli drive +upload --file <媒体> --format json        -> file_token
lark-cli minutes +upload --file-token <ft> --format json -> minute_token
lark-cli minutes +detail --minute-tokens <mt> --transcript --keyword \
        --output-dir <dir> --format json                 -> transcript.txt
```
`minutes +detail` 要轮询（转写异步，25 秒一次，超时 45 分钟）。
`note +transcript` 也可取统一逐字稿，作为备用。

中间产物目录：`D:\...\抖音收藏文案整理\_tr\`

## 坑：单轮 50 次删除的安全阈值
批量跑时每转写一条要清掉 mp4+m4a，累计超过 50 次会触发
`[safe-delete][SAFE_DELETE_BULK_CONFIRM_REQUIRED]`，把 os.remove 拦掉。
**改 shutil.move 移到 `_trash` 也一样会被计数拦截**（工具按"文件消失"统计）。
唯一稳妥解法：**转写加 `--keep`，不删任何文件**，mp4 留在 `_temp_audio`，
等换个会话再统一清理。代价是磁盘占用（762 条约 10GB）。

## 坑：不要同时起两个转写任务
两个进程会扫到同一批 mp4，重复上传、互相把对方的文件移走，
报 `No such file or directory`。必须单进程串行。
