**结构性问题**：

1. **P0 转写引擎选错**｜飞书妙记是外部 SaaS：要授权、慢（`poll_transcript` 最长 45 min）、
   **会串稿（已污染 189 篇）**；防护是补丁（3 组黑名单漏了第 4 组"芯片"正文，
   `_fingerprint_seen` 为内存 set 跨批次失效）。

2. **P0 抖音接口无护栏**｜无独立探针；`douyin_api.py:87` 报错仍指向**不存在的** `src/douyin_spider.py login`（09-20 已发现未修）；

4. **P1 09-23 防护改动未提交**（当晚已应验后果，见文末「工作区被还原」）。

## 抖音访问层实测诊断 —— 推翻此前全部归因

用户提出「先认真做好访问抖音这个功能」。动手前先做实测诊断，
探针脚本 `%TEMP%\dy_diag.py` / `dy_diag2.py` / `dy_diag3.py` / `dy_diag4.py`。

### 实测结果

| 探测项 | 结果 |
|---|---|
| 网络 | **通**。TCP `www.douyin.com:443` 0.06s，TLSv1.3 握手成功 |
| 登录态文件 | 存在，119789 B，2026-09-10 导出 |
| Cookie 有效性 | **有效**。`sessionid` 到期 2026-11-09（剩 31.1 天）、`sid_guard` 剩 331 天、`ttwid`/`odin_tt` 剩 336 天 |
| 缺的 cookie | **`UIFID` 缺失**、`msToken` 缺失（9-10 那份导出就不完整） |
| 公开接口 | 热点榜 200（67KB）、搜索 200（status_code 0）、用户详情 200、首页 HTML 200 —— **全部正常** |
| 需登录接口 | `/collects/list/` 与 `/aweme/detail/` → **HTTP 403，0.52s 返回**，响应体 `Blocked by ArgusSecurityPlugin Uifid Not Found` |
| 补 UIFID | 纯 HTTP 访问一次 `https://www.douyin.com/` 即可下发 `UIFID`（还会新给 `web_sign_token`）。带上后错误变为 **`Signature Not Found`** |
| 传统 a_bogus 签名 | 试了 **7 种摆法**（query / `X-Bogus` 头 / 大小写 / POST / 换成 localStorage 真实 webid `7683902942215669254` / 拼 `x-secsdk-csrf-token` 头）→ **全部 403 同一句** |
| 关键判据 | **连「完全不签名」的变体报的也是同一句 `Signature Not Found`** → 服务端根本没在校验 `a_bogus`，是更前面的插件在拦 |
| 旁路 iesdouyin 老接口 | `/web/api/v2/aweme/iteminfo/` → `status_code 11110 encrypt_data_miss`（老接口也加了新保护） |
| iesdouyin 分享页 | 302 跳回 `www.douyin.com/video/<id>` |

### 结论

**抖音 web 端已把「需登录」的接口整体升级到 secsdk / `ArgusSecurityPlugin` 风控，纯 HTTP + `a_bogus` 方案已经报废。**
这不是改参数能解决的，除非逆向 secsdk（用 Node 补浏览器环境跑抖音自己的保护 JS），工程量极大且抖音一改就废。

**可行路径：Playwright 真浏览器**——让页面自己生成签名，脚本只做编排。
`requirements.txt` 里本来就有 `playwright`，但代码里从未使用过。

### 次因（会误导排查，务必记住）

`src/douyin_api.py` **自己不清理代理环境变量**（只有 `fetch_only.py`、`lark_transcribe.py` 清了）。
本机有 `HTTPS_PROXY`，直接跑 `python src/douyin_api.py` 会走代理被拦，**表现为 read timeout**——
这正是此前「接口 read timeout / IP 被风控」误判的来源。
