## 关键技术结论（用于后续改造）

- **`storage_state.json` 登录态已失效**：实测 aweme/detail 返回 HTTP 403，重跑前必须重新扫码导出登录态。
- **本机无 NVIDIA 独显**（AMD Radeon 集显，Ryzen 7 5800H / 16 线程 / 14G），且**未装 ffmpeg** → 本地 ASR 应选 FunASR paraformer/SenseVoice 的 ONNX CPU 版（faster-whisper 无 GPU 会偏慢）；音频抽取可用已有的 PyAV 代替 ffmpeg。
- **抖音 JSON 里有 `subtitle_infos`（VTT/SRT 字幕轨）**，可直接下载解析成文案，零下载零转写；社区已有 "字幕优先 + 本地 ASR 兜底" 的双层做法。
- 火山方舟（豆包官方 API）：Chat API 支持 video_url，但 VLM 抽帧不理解音轨，拿不到完整口播逐字稿；走 ASR 应选"豆包录音文件识别"（0.8 元/小时，20 小时免费额度）。视频理解正价约 42 元/百万 tokens。
- 豆包 App/网页能解析抖音链接是因为字节自家产品走内部通道，**无对外 REST API**，自动化只能 Playwright 刷 UI，批量不可靠。
