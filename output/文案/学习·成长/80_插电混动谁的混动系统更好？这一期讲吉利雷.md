先来看它的几种工作模式，纯电模式下，电池给 P2 电机供电， P2 电机动力经过 3AT 变速箱，然后才驱动车轮。增程模式。发动机启动， P1 电机发电供给给 P2 电机驱动，多余的电能充到电池。直驱模式，发动机动力直接经过变速箱驱动车轮，跟传统燃油车的动力路径一样，多余的功率还会给 P1 电机发电。并联模式，发动机直驱的动力和 P2 电机动力在 3AT 变速箱内叠加驱动车轮，很明显的就能看出来。这就是一台 3AT 的燃油车，加上了一个 P2 电机，以油为主的车型。 P2 电机动力必须经过变速箱，所以能耗会比较高。但 3AT 变速箱能实现功率分流，虽然只有三个档位，但通过功率分流，它理论上同样可以做到无级变速。而吉利的三挡 MP 是在雷神 8848 的基础上，把 3AT 变速箱换成了平行轴齿轮的三挡，然后把 P2 电机挪到了变速箱后面，成了 P3 电机，也就成了 P1 + P3 架构，成了以电为主，主要搭载在领克系列的混动车型以及雷达系列车型。工作原理也有很大的区别。

P3 放在了变速箱后面，动力不经过变速箱，电机的驱动效率更高，大部分时间应该都是纯电或增程模式， P3 电机驱动能耗更低。爬坡大扭矩需求时，才会用到发动机直驱一档，高速电机扭矩下降，就会用到发动机直驱三档，二档介入应该比较少，只有在长直上坡，扭矩需求高，速度还快的特殊路段才会介入。毕竟在中速段直驱的效率并没有电机驱动效率高。最后吉利还有一个单档MI，在 EMP 架构的基础上减去低速档和中速档，保留高速直驱档，是不是看起来非常熟悉？其实跟比亚迪的 DMI 和奇瑞的单档混动没什么区别，一样的 P1 加 P3 架构，一样的大部分工况 P3 电机驱动。保留高速电机扭矩下降后，发动机直驱，主要搭载在银河系列车型上。目前的插电混动系统原理已经讲了比亚迪、长城、奇瑞、吉利四个车企，老板觉得谁的混动系统更好呢？下期我们讲日产 e- POWER，别忘了点个关注。
