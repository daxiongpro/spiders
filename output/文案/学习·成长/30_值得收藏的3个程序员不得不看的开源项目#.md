第二款，墨商城。学完了基础的管理系统开发后，想要进阶的小伙伴一定要看一下这款开源的电商系统。众所周知，电商系统是所有系统中复杂度较高的系统之一，比如像秒杀、专场活动等业务，无一不是严峻的挑战。这个项目提供了从用户消费到商家管理一体系的前后端生态平台，为不管是企业还是开发者，都提供了良好的借鉴。使大家可以更专心的编写自己的业务需求。更幸运的是，这个项目不仅提供了源码，还提供了详细的开发设计文档以及架构图。这样对于用户来说，我们就可以根据自己的实际场景去定制化的设计以及定制化的开发了。

第三款是阿里开源的阿尔萨斯系统。学完上面两个 Java 系统的开发后，你对 Java 的开发生态和框架有了一个基本的了解和掌握了，那就不得不来看一下如何定位 Java 系统在运行过程中的各种毛病了，包括系统的类运行冲突、缺少日志排查、代码热更新、热点函数定位问题。 Arthas 作为目前诊断 Java 应用的最方便的利器，没有之一，也是一款我们在开发过程中定位 Java 运行时问题的一款神器，能帮我们解决各种 Java 运行时以及系统问题，包括但不仅限于线程、内存、 GC 以及 CPU 等问题。这款工具的源代码中还涉及到了 Java 中比较底层的知识点，诸如类加载机制、字节码替换、热修复、热修改等底层黑科技。如果你有时间去研究 Arthas 底层的源码，对你来说一定受益，还有机会超过 80% 的同行程序员。
