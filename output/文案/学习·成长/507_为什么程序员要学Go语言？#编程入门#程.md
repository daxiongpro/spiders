Go，又称Golang，是 Google 开发的一种静态强类型、编译型、并发型，并具有垃圾回收功能的编程语言。二零零七年九月， Rob Pike 带领的 Google 团队开始设计Go，不久后 Russ Cox 大神也加入了项目。二零零九年十一月，正式宣布推出 Go 语言，并将其源代码开放，成为 GitHub 开源项目。

Speaker 1 00:00:36.790 
同时， Rob Pike 的妻子为这门语言画了个吉祥物，它的原型是土拨鼠，英文叫Gopher，特点就是挖洞速度特别快。作者想通过这个吉祥物形象表达这门语言的运行速度、开发速度、学习速度都像 Gopher 一样快。到了 2016 年， Go 被软件评价公司 TIOBE 选为 TIOBE 2016 年最佳语言。这几年，国内的互联网大厂们陆续开始使用Golang，比如腾讯、字节、米哈游。

Speaker 1 00:01:12.850 
那么 Golang 为什么会这么受欢迎呢？ Go 的语法接近 C 语言，简单易上手，一般有经验的开发人员一个月内就能上手。性能优越，性能接近 C 语言，一般比 Python 要快 30 倍，并且内置提供了丰富的标准库，特别是网络库非常强大，这也是众多开发者选择 Go 的重要原因。

Speaker 1 00:01:39.190 
Go 是静态强类型语言。我们知道，弱类型的语言，很多问题要程序运行的时候才会被暴露出来，这属于埋坑。而静态强类型的语言可以在编译的时候就检查出很多隐藏的问题，这对于开发者非常友好。 Go 代码风格统一， Goland 自带 format 工具，可以使代码风格一键统一化，这对于团队开发非常有利。 C 语言需要自己申请释放内存，稍不留神就有可能导致空指针或内存泄漏问题。而 Go 天然支持垃圾回收功能，写代码的时候无。无需关注内存释放的问题，专心开发业务功能就好了。 Go 天生并发，在语言级别就支持协程并发，在高并发场景中表现出强悍的优势。并且， Go 可直接编译成可执行文件，不依赖任何东西，部署就是扔一个文件上去就完成了，这点非常重要，无论是个人开发还是工作中的很多任务，尤其在需要到服务器上跑的最方便了，不需要配置环境什么的，相比 Python 好太多。在可见的未来里，会有越来越多的开发者和公司加入到 Go 的队伍中。
